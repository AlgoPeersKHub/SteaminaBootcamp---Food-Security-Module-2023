# SteaminaBootcamp---Food-Security-Module-2023

This repository showcases codes K–12 learners aged 7–15 developed in the Food Security module of the After-School Program. Using the BBC micro:bit (programmed with Microsoft MakeCode) and electronics, learners built practical solutions to agricultural challenges such as irrigation systems, pest detection tools, and seedling transplantation devices. Guided by Constructionism (Papert, 1980), the module engaged learners in hands-on making; through Culturally Relevant Pedagogy (Ladson-Billings, 1995), projects were rooted in local farming practices; Universal 

Design for Learning (CAST, 2018) supported inclusive participation across diverse abilities; and Social Constructivism (Vygotsky, 1978) fostered peer collaboration and shared problem-solving. Together, these approaches empowered learners to connect coding and physical computing with sustainable farming practices and the global call for SDG 2: Zero Hunger.
